# 🎮 Player API - NestJS

Uma API RESTful desenvolvida como estudo prático do framework NestJS, focada na construção de um CRUD de jogadores para consolidar o entendimento da estrutura, módulos e controladores no ambiente Node.js.

## 🎯 Objetivo do Projeto

Este projeto foi construído do zero como um estudo prático e intensivo para explorar o ecossistema **NestJS** e **TypeScript**. 

## 🛠️ Tecnologias Utilizadas

* **Framework:** NestJS
* **Linguagem:** TypeScript
* **ORM:** TypeORM
* **Banco de Dados:** SQLite (`better-sqlite3`) - *Escolhido para prototipagem rápida*

## ⚙️ Estrutura da Entidade (Player)

* `id`: Identificador único.
* `name`: Nome de usuário.
* `balance`: Saldo (moedas/carteira).
